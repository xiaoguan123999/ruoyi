# ruoyi

若依前后端分离项目（Spring Boot 2 + Vue3 TypeScript）。

## 目录

- `RuoYi-Vue-springboot2`：后端（JDK 8，端口 8080）
- `RuoYi-Vue3-typescript`：前端（Node.js，端口 80）

## 启动

1. 启动 MySQL（库名 `ry-vue`）和 Redis
2. 导入 `RuoYi-Vue-springboot2/sql/` 下的 SQL
3. IDEA 运行 `RuoYiApplication`
4. 前端目录执行 `npm install` 后 `npm run dev`

默认账号：`admin` / `admin123`
